# 1. Необходимо создать файл с расширением .env и разместить в той же папке, 
где лежат скрипты тестов (например, в директории lesson_08).
В файле вручную прописать:

API_TOKEN=заполнится автоматически после шага 3.
LOGIN=логин
PASSWORD=пароль
ID_COMPANY=заполнится автоматически после шага 2.
# 2. Далее вручную запустите файл setup_company_id.py. Команда:
    python lesson_08/setup_company_id.py

После запуска ID компании автоматически запишется в файл.
# 3. Запустите setup_token.py вручную. Команда:

    python lesson_08/setup_token.py

После запуска ТОКЕН автоматически запишется в файл.
# 4. Запустите команду pytest lesson_08 -s -v
